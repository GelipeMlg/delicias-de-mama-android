# Generadores y utilidades

- `generar_resumen_bd.py`: genera `docs/entregables/Resumen_base_de_datos_Delicias_de_Mama.docx` a partir del contenido definido en el script. Requiere Python y `python-docx`.

Los cambios de contenido o presentación del resumen se trabajan habitualmente en `codex/documentacion`. El script genera el archivo, pero no realiza la revisión visual del documento. Revisar la salida antes de entregar una nueva versión.

Los scripts deben ejecutarse desde la raíz del repositorio y escribir sus resultados en la carpeta del área correspondiente. Las herramientas descargadas y resultados temporales quedan en `.tmp/`, excluida de Git.
